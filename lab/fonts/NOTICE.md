# Bundled typefaces

The Lab uses local WOFF2 fonts, so opening the interface does not request fonts
from an external service. The following projects provide these typefaces:

| Family | Copyright and source | License |
|---|---|---|
| Public Sans | The Public Sans Project Authors; [USWDS](https://github.com/uswds/public-sans) | [SIL OFL 1.1](licenses/publicsans-OFL.txt) |
| Chivo | The Chivo Project Authors; [Omnibus-Type](https://github.com/Omnibus-Type/Chivo) | [SIL OFL 1.1](licenses/chivo-OFL.txt) |
| Azeret Mono | The Azeret Project Authors; [Displaay](https://github.com/displaay/azeret) | [SIL OFL 1.1](licenses/azeretmono-OFL.txt) |

The license texts are reproduced from the corresponding official Google Fonts
directories. These fonts retain their own licenses and are not covered by the
repository's MIT source-code license.
